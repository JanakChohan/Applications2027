# Specimen letters

The `/coverletter` command reads `examples/optiver.md` if it exists and treats it
as the **gold-standard specimen** — the letter that defines the target register,
tone, and structure for everything it drafts.

## Add your specimen

Save your best real cover letter here as `optiver.md` (keep the filename — the
command looks for it by name). The stronger the specimen, the better every draft
that follows, because Phase 4's "register check" reads the draft back against it.

A good specimen is one that works for reasons a prompt cannot manufacture:
a real connection, a real conversation with a named person, and a genuine way of
thinking that matches the firm's. It should show, not just tell:

- a bespoke narrative opening — mid-story, not "I am writing to apply for"
- motivation that emerges from a sequence of events, not from asserted adjectives
- hard-varied sentence length; semicolons and em dashes used with intent
- at least one honest concession that makes the surrounding claims credible
- numbers over adjectives, and no banned filler (see the command for the list)

If no specimen is present, the command still runs — it just falls back to the
register rules written into the command itself.
